# Synlexa Studio

> **RESEARCH-USE-ONLY (RUO):** Synlexa Studio and all outputs generated by its Rust, C++20, WebAssembly, CLI, Python/TypeScript SDKs, compute bridge, and Web IDE are strictly for exploratory computational research and software evaluation. They are **not** intended for diagnostic, therapeutic, clinical-decision, or medical-device use.

**Open scientific tools. Commercial cloud infrastructure.**

Synlexa Studio is an **Apache License 2.0** computational biology and cheminformatics workbench combining a zero-dependency pure-Rust domain core (`synlexa-bio-core`), a WebAssembly (`wasm32-unknown-unknown`) browser worker, a C++20 reference library, a React + Mol\* + RDKit WASM Web IDE, a native desktop host, Python and TypeScript SDKs, an in-app/stdio MCP server, and a self-hosted GPU compute bridge (`synlexa-compute`).

Every local scientific workflow runs **100% offline with zero account or subscription required**.

## Offline Open-Source Capabilities vs. Optional Synlexa Cloud

| Capability | Open-Source Local (`Apache-2.0`) | Optional Synlexa Cloud (`synlexa.com`) |
|---|---|---|

| Peptide biophysics, 3D pocket contact shells (`< 5.0 Å`), MANE Select / CRISPR PAM scanning | Runs offline | — |
| SMILES descriptors, 2D RDKit WASM sketcher, PAINS/Brenk alerts & SVG depiction | Runs offline | — |
| AI research assistant & Web Search (Europe PMC, ClinicalTrials.gov, RCSB, PubChem, UniProt, ChEMBL, Open Targets) | Bring-Your-Own-Key (Anthropic, Gemini, OpenAI) stored in encrypted `state.vscdb` | Hosted Synlexa Cloud assistant (`OAuth2 PKCE`), team quotas & metered billing |
| External GPU Compute (`AutoDock Vina`, `OpenMM`, `Boltz-2`, `PySCF`, `GROMACS`, Colab T4/L4/A100) | Self-hosted `services/compute-worker` via localhost, Docker, or Colab tunnel | Managed high-throughput compute & team pipelines (`synlexa-core`) |
| Biomarker discovery ranking & analyst-reviewed translational reports | — | Proprietary commercial SaaS (`synlexa.com`) |

## Quick Installation

### 1. One-Line Terminal Install (macOS & Linux)

```bash
curl -fsSL https://github.com/Synlexa/synlexa-studio/releases/latest/download/install.sh | sh
synlexa-studio
```

Or via CDN mirror:

```bash
curl -fsSL https://www.synlexa.com/install.sh | sh
```

### 2. Windows PowerShell

```powershell
irm https://github.com/Synlexa/synlexa-studio/releases/latest/download/install.ps1 | iex
synlexa-studio
```

### 3. Homebrew (macOS Apple Silicon / Intel & Linux)

```bash
brew tap Synlexa/tap
brew install synlexa-studio
# Optional macOS .app bundle Cask:
brew install --cask Synlexa/tap/synlexa-studio
```

*(Note: Homebrew 7.0+ prompts once to trust third-party taps via `brew trust Synlexa/tap`.)*

### 4. npm (Cross-Platform Launcher & Wasm MCP Server)

```bash
npm install -g https://github.com/Synlexa/synlexa-studio/releases/download/v0.4.0/synlexa-studio-0.4.0.tgz
synlexa-studio

# Or embed the Wasm bio-core SDK directly in Node/TS projects:
npm install https://github.com/Synlexa/synlexa-studio/releases/download/v0.4.0/synlexa-wasm-bridge-0.4.0.tgz
```

### 5. Prebuilt Desktop & Binary Archives

Download signed checksum digests (`SHA256SUMS.txt`) and platform packages from [GitHub Releases](https://github.com/Synlexa/synlexa-studio/releases) or [synlexa.com/download](https://www.synlexa.com/download):

- **macOS Universal (`arm64` + `x86_64`)**: `.dmg` app bundle & `.tar.gz`
- **Windows (`x64` & `arm64`)**: `.zip`
- **Linux (`x86_64` & `aarch64`)**: `.AppImage`, `.deb`, `.tar.gz`
- **Hosted Web App**: [https://studio.synlexa.com](https://studio.synlexa.com)

See [`docs/installation.md`](docs/installation.md) for full checksum verification, Docker GPU, Google Colab notebook, and source build instructions.

## Developer Quickstarts

### Native Rust CLI (`studio-cli`)

```bash
# Compare experimental mmCIF against AlphaFold DB v6 prediction + PAE uncertainty
cargo run -p studio-cli -- compare \
  --ref tests/fixtures/3HS4.cif --ref-chain A \
  --mob tests/fixtures/AF-P00918-F1-model_v6.cif --mob-chain A \
  --pae tests/fixtures/AF-P00918-F1-predicted_aligned_error_v6.json \
  --pretty

# Analyze peptide mutation + 3D active-site contacts (< 5.0 A around residue 94)
cargo run -p studio-cli -- peptide \
  --seq MSHHWGYGKHNGPEHWHKDFPIAKGERQSPVDIDTHTAKYDPSLKPLSVSYDQATSLRIL \
  --mut H10A --structure tests/fixtures/3HS4.cif --chain A --focus 94 --pretty

# Trace MANE transcript codon edit + CRISPR PAM windows
cargo run -p studio-cli -- gene \
  --transcript NM_000518.5 --codon 7 --edit-bp 2 --new-base T --nuclease SpCas9 --pretty

# Compute SMILES properties & 2D vector layout
cargo run -p studio-cli -- smiles \
  --name Acetazolamide --smiles "CC(=O)Nc1nnc(S(N)(=O)=O)s1" --pretty

# Backbone Ramachandran (phi, psi) & Ca-Ca contact map
cargo run -p studio-cli -- ramachandran --input tests/fixtures/3HS4.cif --chain A --pretty
```

### TypeScript / JavaScript WebAssembly SDK (`@synlexa/wasm-bridge`)

```bash
node examples/protein-structures/compare_ca2.mjs
```

```ts
import { readFile } from 'node:fs/promises';
import { loadWasmBioCore } from '@synlexa/wasm-bridge';

const wasmBytes = await readFile('apps/web/public/wasm/synlexa_bio_core.wasm');
const session = await loadWasmBioCore(new Uint8Array(wasmBytes));
const res = session.invokeJson('analyze_molecule_smiles', {
  name: 'Acetazolamide',
  smiles: 'CC(=O)Nc1nnc(S(N)(=O)=O)s1',
});
console.log(res.data?.formula, res.data?.molecularWeight);
```

### Python SDK (`synlexa-studio-sdk`) & Compute Node Client

```bash
pip install -e ./bindings/python
python3 examples/molecular-workflows/run_sdk_demo.py
```

```python
from synlexa_sdk import SynlexaStudioClient

studio = SynlexaStudioClient()
cmp_res = studio.compare_structures(
    "tests/fixtures/3HS4.cif",
    "tests/fixtures/AF-P00918-F1-model_v6.cif",
    ref_chain="A",
    mob_chain="A",
    pae_path="tests/fixtures/AF-P00918-F1-predicted_aligned_error_v6.json",
)
print(cmp_res["metrics"]["matchedCaCount"], cmp_res["metrics"]["rmsdAngstrom"])
```

## Build & Verify From Source

```bash
rustup target add wasm32-unknown-unknown
pnpm install
node scripts/prepare-wasm.mjs

# Verify unified version across Rust, Tauri, npm, Python, and installers
node scripts/check-version-sync.mjs

# Run Rust, Desktop Native, Web IDE, C++20, Python & Parity tests
cargo test --workspace --locked
cargo test --manifest-path apps/desktop/native/Cargo.toml --locked
pnpm --filter @synlexa/studio-web lint
pnpm --filter @synlexa/studio-web test
pnpm --filter @synlexa/studio-web build

cmake --preset native-debug && cmake --build --preset native-debug && ctest --preset native-debug --output-on-failure
cargo build -p studio-cli --release && node benchmarks/run_benchmarks.mjs
PYTHONPATH=bindings/python python3 -m unittest discover -s bindings/python/tests -v
python3 -m pytest services/compute-worker/tests -q
```

## Repository Structure

```text
synlexa-studio/
├── crates/
│   ├── synlexa-bio-core/        # Pure-Rust std domain engine (0 crates.io deps)
│   ├── studio-cli/              # Native Rust CLI + stdio MCP server
│   └── studio-wasm/             # wasm32 ABI v1 cdylib export
├── core/                        # C++20 reference structural library & CTest suite
├── tools/studio-cli/            # C++20 CLI executable (studio-cli-cpp)
├── bindings/
│   ├── wasm/                    # TypeScript Wasm bridge (@synlexa/wasm-bridge + ABI.md)
│   └── python/                  # Zero-dep Python SDK (synlexa-studio-sdk)
├── apps/
│   ├── web/                     # Offline React + Vite + Mol* + RDKit WASM IDE
│   └── desktop/
│       ├── native/              # Zero-dep Rust HTTP/MCP host + macOS AppKit WebView
│       └── src-tauri/           # Standalone Tauri v2 desktop scaffold
├── services/compute-worker/     # FastAPI/Docker/Google Colab GPU bridge (synlexa-compute)
├── schemas/                     # JSON schemas (ComparisonResultV1, PluginV1)
├── examples/                    # Runnable shell, Node.js/Wasm, and Python workflows
├── benchmarks/                  # Native-vs-Wasm IEEE-754 parity & latency harness
├── tests/fixtures/              # Pinned RCSB PDB / AlphaFold DB / PubChem benchmarks + SHA-256 manifest
├── docs/                        # Installation, SDK/MCP, Scientific Methods, Cloud & Contributor Sync guides
└── packaging/                   # Multi-OS curl, PowerShell, npm, and Homebrew packaging
```
